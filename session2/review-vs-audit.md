# Code Review vs Configuration Audit

A code review is done to check proposed changes before merging them, just like how I reviewed Pull Request #2 to make sure the changes met the acceptance criteria. A formal configuration audit is a planned and independent process that checks whether a product meets its requirements and approved configuration. A Functional Configuration Audit (FCA) checks whether the product functions as required, while a Physical Configuration Audit (PCA) checks whether the actual product matches its documentation.
