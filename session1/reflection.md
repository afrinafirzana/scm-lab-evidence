Reflection - Practical Activity 1

Q1: Commit history is useful because it allows developers to track changes made to a project over time. It helps us understand what was changed, when it was changed, and who made the changes. For example, I used the git log --oneline to see my previous commits, such as "Add .gitignore". If something goes wrong, we can check the history to find out which change might have caused the problem.

Q2: Git is a tool used to track and save changes to files on our computer. GitHub is an online platform where we can store and share our Git projects. For example, I used Git commands like git add and git commit in my scm-lab-evidence folder. I also used GitHub to complete the skills-introduction-to-github exercise and upload my project.

Q3: Branches let us make changes without affecting the main project. Pull requests allow others to check our work first. For example, I created my-first-branch and used a pull request to add PROFILE.md. This way, we can avoid mistakes before adding changes to the main branch.

Q4: Commands like git init, git add, git commit, git log, and git status work only on my MacBook. They help me save and check my changes without using GitHub. Commands like git push, git pull, and git clone involve GitHub. I used these commands to upload my files and get changes from GitHub.
